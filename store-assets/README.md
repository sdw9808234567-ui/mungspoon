**자세한 설명** (4000자 이내)
```
우리 강아지를 위한 건강한 한입, 멍스푼 🐶

집에 있는 재료로 강아지 수제간식을 만들고 싶은데,
"이 재료 강아지가 먹어도 될까?" 고민되셨나요?
멍스푼은 재료의 안전성을 먼저 확인하고, 통과한 재료로만 레시피를 만들어 드려요.

■ 재료 안전성 검사
- 포도·건포도·양파·마늘·자일리톨·초콜릿처럼 강아지에게 위험한 재료는 자동으로 막아요.
- 재료마다 '사용 가능 / 조건과 양에 주의 / 사용 금지 / 정보 부족' 4단계로 알려 드려요.
- 주의사항, 조리 방법, 참고한 출처까지 함께 보여 드려요.
- 양념·가당 가공품처럼 판단이 어려운 재료는 무리하게 쓰지 않고 '분석 보류'로 안내해요.

■ 내 재료로 간식 만들기
- 쿠키, 강아지 빵, 머핀, 케이크, 푸딩, 도넛, 한입 간식, 말랑한 간식까지 8가지 종류.
- 재료만 고르면 계량(g), 조리 온도, 조리 시간, 익힘 확인 방법을 한눈에 정리해요.
- 설탕·소금·버터·기름을 넣지 않는 무첨가 기본 배합으로 만들어요.
- 보관 방법과 보관 기간, 예상 열량(전체 kcal)도 함께 알려 드려요.

■ 우리 아이 맞춤
- 강아지 프로필에 알레르기·먹으면 안 되는 재료를 등록하면 레시피에서 자동으로 빼 드려요.
- 건강 메모는 급여 시 주의사항에 반영돼요.

■ 보관함
- 만든 레시피, 즐겨찾기, 직접 만든 기록(메모·사진)을 한곳에 모아 볼 수 있어요.

■ 개인정보 걱정 없이
- 회원가입이 없어요. 프로필과 기록은 사용자의 휴대폰에만 저장돼요.

※ 안내
멍스푼의 레시피는 일반적인 무첨가 간식 배합 규칙으로 만든 참고용 레시피예요.
간식은 주식이 아니며, 처음 주는 재료는 아주 조금만 주고 반응을 살펴 주세요.
```

## 2. 미리 알아 둘 것 (솔직하게)

- **구글 개발자 계정 등록비 25달러(1회)가 필요해요.** 앱 등록 자체는 무료가 아니에요. 웹사이트(Vercel)는 계속 무료예요.
- **신분증 인증**이 필요해요. 며칠 걸릴 수 있어요.
- **새 개인 계정은 '비공개 테스트'를 먼저 해야 해요.** 테스터 **12명 이상**이 **14일 동안 계속** 참여해야 정식 출시를 신청할 수 있어요.
  유튜브 구독자, 지인에게 미리 부탁해 두면 좋아요. (구글 정책은 바뀔 수 있으니 콘솔 안내를 우선해 주세요)
- 휴대폰으로도 할 수 있지만, 플레이 콘솔은 PC 화면에 맞춰져 있어요. 크롬에서 **"데스크톱 사이트"**를 켜면 편해요.

## 3. 단계별 순서 (휴대폰 크롬 기준)

### 1단계: 안드로이드 앱 파일 만들기 (PWABuilder, 무료)
1. 크롬에서 **pwabuilder.com**에 접속해요.
2. 입력칸에 내 Vercel 주소(예: `https://mungspoon.vercel.app`)를 넣고 **Start**를 눌러요.
3. 점수 화면이 나오면 **Package For Stores** → **Android** → **Generate Package**를 눌러요.
4. 옵션에서 **Package ID**를 확인해요. (예: `com.barunmeong.mungspoon`) ← 나중에 바꿀 수 없으니 신중하게!
5. **Download**를 누르면 zip 파일이 받아져요.
   - `.aab` 파일: 플레이스토어에 올릴 앱 파일
   - `signing.keystore`, `signing-key-info.txt`: **앱 열쇠예요. 잃어버리면 업데이트를 못 해요.**
     구글 드라이브 같은 안전한 곳에 꼭 따로 보관하세요.
   - `assetlinks.json`: 다음 단계에서 쓸 정보가 들어 있어요.

### 2단계: 웹사이트와 앱 연결하기 (Vercel 환경변수 2개)
주소창 없이 진짜 앱처럼 보이게 하는 단계예요. 코드는 고칠 필요 없어요.
1. 받은 `assetlinks.json` 파일을 열어 `package_name`과 `sha256_cert_fingerprints` 값을 확인해요.
2. Vercel → 내 프로젝트 → **Settings → Environment Variables**에 아래 2개를 추가해요.
   - `TWA_PACKAGE_NAME` = package_name 값 (예: `com.barunmeong.mungspoon`)
   - `TWA_SHA256` = 지문 값 (예: `AB:CD:12:...`)
3. **Deployments → 맨 위 ⋯ → Redeploy**를 눌러요.
4. 확인: `https://(내 주소)/.well-known/assetlinks.json`을 열었을 때 값이 보이면 성공이에요.

### 3단계: 플레이 콘솔 가입 & 앱 만들기
1. **play.google.com/console**에서 개발자 계정을 만들고 등록비를 결제해요. 신분증 인증도 해요.
2. **앱 만들기** → 앱 이름 `멍스푼 - 강아지 수제간식 레시피`, 언어 한국어, 앱, 무료를 선택해요.
3. **스토어 등록정보**에 위 1번의 문구와 이 폴더의 이미지를 올려요.
4. **앱 콘텐츠**에서 개인정보처리방침 URL, 광고 없음, 콘텐츠 등급, 타깃 연령, 데이터 보안을 차례로 답해요.

### 4단계: 비공개 테스트 → 정식 출시
1. **테스트 → 비공개 테스트**에서 트랙을 만들고 `.aab` 파일을 올려요.
2. 테스터 이메일(12명 이상)을 등록하고 참여 링크를 보내요.
3. **중요:** 업로드 후 **설정 → 앱 무결성(App signing)**에 나오는 **"앱 서명 키 인증서 SHA-256"**을 복사해요.
   Vercel의 `TWA_SHA256`에 쉼표(,)로 이어 붙이고 다시 Redeploy해요.
   (예: `PWABuilder지문,구글지문`) → 이걸 안 하면 플레이스토어 앱 위에 주소창이 보여요.
4. 14일 테스트가 끝나면 **프로덕션 출시**를 신청해요. 심사는 보통 며칠 걸려요.
