# 멍스푼 (MUNG SPOON)

우리 강아지를 위한 건강한 한입 — 집에 있는 재료의 **안전성을 먼저 확인**하고, 통과한 재료로만 수제간식 레시피를 만드는 웹앱입니다.

## 지금 되는 것 (2026-11-14 기준, 실제 실행해 확인함)

- 재료 12종 선택 + 직접 입력 → 서버에서 안전성 분석 (4단계 분류, 주의사항·조리법·첨가물·알레르기·출처 표시)
- 위험 재료(포도·자일리톨·초콜릿·양파·마늘 등)가 하나라도 있으면 레시피 생성 중단
- DB에 없는 재료·가공품은 "분석 보류"로 레시피에서 제외
- 8종류 간식 레시피 생성 (g 계량, 온도, 시간, 익힘 확인, 보관, 급여 주의, 열량 계산 근거)
- 강아지 프로필 저장 → 알레르기·금지 재료가 들어간 레시피는 만들지 않음
- 보관함: 최근 생성 / 즐겨찾기 / 만든 기록(메모 + 사진)

## 아직 안 되는 것 (솔직하게)

| 항목 | 상태 |
|---|---|
| 실제 AI 레시피 | 연결 코드는 있지만 **유료 API 키가 없어 실제 AI 응답은 테스트하지 못함**. 키가 없으면 규칙 기반 "기본 레시피"로 동작 |
| Supabase(온라인 DB) | **미연결**. 지금은 휴대폰 브라우저에만 저장 (기기를 바꾸면 안 보임) |
| 완성 이미지 | 종류별 예시 그림. 실제 사진은 "만든 기록"에 직접 올림 |
| 기본 레시피 배합 | 일반적인 무첨가 간식 비율을 규칙화한 것. **모든 조합을 실제로 구워 검증하지 않음** |
| 인기 수제간식 | 이용 통계가 없어 "기본 수제간식" 조합으로 표시 |
| 열량 | 일반 식품성분표 근사값. 정식 서비스 전 국가표준식품성분표로 재확인 권장 |

## 폴더 구조

```
src/
  app/                  화면과 서버 API
    page.tsx            홈
    make/               내 재료로 간식 만들기
    check/              재료 안전성 검사
    recipe/             레시피 상세
    box/                보관함
    profile/            강아지 프로필
    blog/               블로그 연결
    api/analyze/        [서버] 재료 안전성 분석
    api/recipe/         [서버] 레시피 생성
  components/           화면 부품 (버튼, 내비게이션, 재료 선택 흐름)
  lib/
    safety/db.ts        ★ 안전성 데이터베이스 (판정 기준 + 출처)
    safety/analyze.ts   서버 측 재료 검증·판정
    recipe/demo.ts      기본(규칙 기반) 레시피 생성기
    recipe/validate.ts  결과 검증 (AI가 만든 레시피도 여기서 다시 검사)
    recipe/generate.ts  전체 흐름 총괄
    ai/provider.ts      AI 연결부 (모델 교체는 이 파일만)
    store.ts            기기 저장소
tests/                  자동 테스트 (API 43개, 모바일 화면 48개 항목)
```

## 안전 구조

```
사용자 입력 → 서버 재료 검증 → 안전성 판정(DB) → 레시피 생성(AI 또는 기본)
          → 결과 검증(DB) → 주의사항·열량 붙이기(DB) → 화면 표시
```

- AI는 "통과한 재료 목록"만 받고, AI의 답도 DB로 다시 검사합니다. 탈락하면 기본 레시피로 대체합니다.
- API 키는 서버 환경변수로만 읽습니다 (브라우저용 파일에 포함되지 않음을 확인).

## Vercel 배포 (무료 Hobby 요금제로 가능)

1. 이 폴더를 GitHub 저장소에 올립니다.
2. vercel.com 로그인 → **Add New… → Project** → 저장소 선택 → **Deploy**.
3. (선택) **Settings → Environment Variables** 에 `.env.example` 의 값을 입력 후 **Redeploy**.
   - `NEXT_PUBLIC_BLOG_URL` : 네이버 블로그 주소를 바꿀 때만 (기본값이 코드에 들어 있음)
   - `AI_PROVIDER=anthropic`, `ANTHROPIC_API_KEY` : AI 사용 시 (유료, 사용량만큼 과금)
